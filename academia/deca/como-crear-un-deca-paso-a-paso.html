Academia TrazaQR · Documento Electrónico de Control Administrativo (DeCA)

¿Cómo se crea un DeCA paso a paso?

Crear un DeCA no es simplemente hacer un PDF y ponerle un código QR. Primero se reúnen los datos obligatorios del transporte, con ellos se genera un documento electrónico, ese documento se aloja en un repositorio y el código QR permite acceder directamente a él.

En este vídeo de Academia TrazaQR te explicamos cómo se crea realmente un DeCA: los datos del transporte, el PDF generado, el repositorio donde se aloja y el código QR de acceso.

Lo importante en 30 segundos

  • El DeCA se genera a partir de los datos obligatorios del transporte: cargador contractual, transportista efectivo, origen, destino y mercancía.
  • También hacen falta la fecha de realización del transporte y los datos del vehículo, incluida la matrícula.
  • Con esos datos se genera un PDF creado electrónicamente — no basta con fotografiar o escanear un documento en papel.
  • Ese PDF se guarda en un repositorio: el lugar online donde queda almacenado para poder recuperarlo.
  • El repositorio no es del Ministerio: puede ser propio de la empresa o de un proveedor de software.
  • El DeCA incorpora un código QR que da acceso directo a ese PDF, sin usuario ni contraseña.

¿Qué datos necesitas para crear un DeCA?

El punto de partida son los datos obligatorios del transporte que exige el artículo 6 de la Orden FOM/2861/2012: quién contrata el transporte, quién lo realiza materialmente, el origen y el destino del envío, y la mercancía transportada.

Consulta aquí qué es el DeCA y qué datos exige exactamente, y quién puede generar el documento: el cargador, el transportista o un tercero contratado para hacerlo.

¿Qué más hace falta además de esos datos?

Se necesita también la fecha de realización del transporte y los datos del vehículo utilizado, incluida su matrícula.

¿Cómo se genera el documento?

Con esos datos se genera el documento electrónico. Tiene que ser un PDF creado a partir de los datos introducidos; no es válido fotografiar o escanear un documento en papel.

¿Qué es el repositorio del DeCA?

Ese PDF se guarda en lo que la normativa llama un repositorio. Dicho de forma sencilla, es el lugar online donde está almacenado el documento para poder recuperarlo cuando sea necesario.

No es un repositorio del Ministerio. Puede ser propio de la empresa o de un proveedor de software contratado para prestar ese servicio.

¿Para qué sirve el código QR?

Cada PDF tiene una dirección única y el DeCA incorpora un código QR que permite acceder directamente a ese documento. El acceso debe ser directo, sin usuario ni contraseña. Consulta aquí qué debe llevar el conductor para acreditar el DeCA con ese QR durante el transporte.

Resumen del proceso

En resumen: reúnes los datos del transporte, generas el PDF a partir de ellos, lo alojas en un repositorio y el código QR permite acceder directamente al documento. Consulta aquí qué pasa si no existe el DeCA en un control de carretera si alguno de estos pasos falla.

¿Cómo lo hace TrazaQR?

Qué dice la normativa

La Orden FOM/2861/2012 establece los datos que debe contener el documento de control administrativo (art. 6).

La Resolución de 5 de junio de 2026 determina las características que deben reunir los sistemas y documentos electrónicos de control administrativo: el PDF generado a partir de datos, el repositorio donde se aloja y el código QR de acceso directo, sin usuario ni contraseña.
